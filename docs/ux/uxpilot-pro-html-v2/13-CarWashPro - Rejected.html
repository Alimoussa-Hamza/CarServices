Dossier refusé

Votre dossier n'a pas pu être validé pour le motif suivant :

Document RC Pro illisible

L'attestation d'assurance fournie est trop floue ou incomplète. Merci d'en envoyer une version lisible et à jour.

Comment corriger ?

1. Reprenez une photo nette du document en entier

2. Vérifiez que la date d'expiration est visible

3. Renvoyez votre dossier pour une nouvelle vérification
