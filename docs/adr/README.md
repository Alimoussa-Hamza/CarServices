## Processus

1. Proposer ADR en PR avant changement majeur
2. Review tech lead + PO si impact produit
3. Statuts : `Proposé` → `Accepté` | `Rejeté` | `Déprécié`
4. Une fois accepté, implémenter — ne pas contredire sans nouvel ADR
